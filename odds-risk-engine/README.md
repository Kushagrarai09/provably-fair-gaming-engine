# Odds & Sportsbook Risk Engine

Educational full-stack sportsbook risk simulation using virtual credits only.

Features:
- Decimal, fractional and American odds conversion
- Implied probability, overround and proportional margin removal
- Virtual-credit singles and accumulators with accepted-odds snapshots
- Liability dashboard and outcome-level exposure estimates
- Simulated live-match feed and WebSocket odds updates
- Match settlement, idempotent payout ledger entries and simulated cash-out
- Django REST Framework, PostgreSQL, Redis, React, TypeScript and Docker Compose

This project is a learning prototype. It does not support real-money wagering, deposits, withdrawals or redeemable credits.

See the project source and Docker setup in the repository's `odds-risk-engine/` directory.
